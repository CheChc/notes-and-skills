# notes-and-skills

计算机系统架构学习笔记（Obsidian vault）与 note-organizer skill 的合集。

## 目录

- `notes/` — Obsidian 笔记库：计算机系统架构主线（内存之下 → 内存 → 内存之上 → 软件）
  - 索引入口：`notes/计算机系统架构/学习地图.md`
- `skill/note-organizer/` — 学习笔记整理助手 skill（研究 → 分门别类 → 写作 → 全库校验）

## 使用

1. 用 Obsidian 打开 `notes/` 作为 vault（已附带基础配置，不含插件）。
2. 从 `计算机系统架构/学习地图.md` 开始阅读，框架图与两条主线覆盖全部 15 篇笔记。
3. skill 安装：将 `skill/note-organizer/` 复制到你的 skills 目录（如 `~/.agents/skills/note-organizer/`）。
