# CGR 和 PLL：时钟生成与复位

> "内存之上"的第一层基础设施：**没有稳定的时钟，后续的寄存器写入、复位释放与初始化均无从进行**。本文讲 PLL 怎么把低频参考时钟变成高频接口时钟、时钟树与复位域怎么组织，以及它们如何决定 HBM 固件的解复位时序（[[固件启动全流程]] 的前提）。
>
> 相关笔记：[[固件启动全流程]] · [[PHY]] · [[带宽和频率]] · [[大核与小核]]

## 一、PLL（Phase-Locked Loop）：倍频原理

### 1.1 为什么需要 PLL

- 外部参考时钟通常很慢（如 100MHz 晶振/PCIe 参考钟），而 HBM 接口需要 GHz 级时钟（HBM3E 命令时钟 ~2.4-4.8GHz 区间）。
- PLL 把参考时钟**倍频**到目标频率，并保持相位锁定。

### 1.2 PLL 工作原理

```mermaid
flowchart LR
    REF["参考时钟 f_ref"] --> PFD["鉴频鉴相器 PFD"]
    PFD -->|"误差信号"| CP["电荷泵/环路滤波器"]
    CP --> VCO["压控振荡器 VCO"]
    VCO --> OUT["输出时钟 f_out"]
    OUT -->|"反馈"| DIV["分频器 ÷N"]
    DIV --> PFD
```

**闭环逻辑**：PFD 比较参考时钟与"输出÷N"，误差驱动 VCO 调整频率，直到两者锁相 → `f_out = N × f_ref`。

| 概念 | 含义 | 工程意义 |
|------|------|---------|
| **Lock（锁定）** | 相位差收敛到稳定范围 | **锁定前不能用输出时钟**——固件必须等 lock 状态位 |
| VCO 频率范围 | 可调范围 | 决定支持的数据率档位 |
| 抖动（Jitter） | 时钟边沿的随机偏移 | 直接缩小数据眼图 margin（[[Training：校准与训练全流程]]） |
| 分频比 N | 倍频倍数 | 频率规划的输入 |

> **要点**：固件在解复位前必须等待 PLL lock——未锁定的时钟边沿抖动极大，会导致寄存器采样亚稳态与训练结果漂移，使所有基于时钟的操作失真。

## 二、时钟树（Clock Tree）

```
晶振/外部参考 ──▶ PLL（倍频）──▶ 分频 ──▶ 各功能域
                                   ├─▶ 核时钟（CPU/NPU 核）
                                   ├─▶ 总线/互连时钟
                                   ├─▶ 内存控制器时钟（与 HBM 同步）
                                   └─▶ PHY 时钟（HBM 接口，[[PHY]]）
```

- **时钟域（clock domain）**：不同频率/相位的时钟区域，跨域信号需要同步器（避免亚稳态）。
- **频率缩放（DVFS）**：运行时调频（降低功耗）→ 内存接口频率变化 → 可能触发**重训练**（[[Training：校准与训练全流程]] 的运行期监控）。
- **偏斜（skew）**：时钟到达各模块的时间差 → PHY 用 DLL 补偿。

## 三、复位（Reset）体系

### 3.1 复位层次

```
POR（上电复位）→ 芯片级软复位 → 子系统复位（内存/PCIe/显示…）→ 模块级复位（PHY/控制器）
```

每个层次都有独立控制与状态，解复位顺序见 [[固件启动全流程]]（电源 → 时钟 → 逐级复位 → CKE）。

### 3.2 复位与时钟的依赖

| 依赖 | 原因 |
|------|------|
| 解复位需要时钟稳定 | 寄存器要时钟才能写入/采样 |
| PLL 需要先于复位释放 | PHY/控制器的复位释放后立刻要有效时钟 |
| DRAM RESET_n 最后 | HBM 复位释放后需要命令时钟 + CKE 序列 |

> **要点**：复位释放必须发生在时钟稳定之后；时钟与复位由 CGR（Clock Generation & Reset）模块统一管理。

---

## 四、CGR 模块的固件接口（HBM 厂商视角）

- 固件通过 CGR 寄存器完成：选时钟源 → 配 PLL（分频比/带宽）→ 等 lock → 使能时钟 → 逐级解复位 → 查状态。
- 错误场景：PLL 失锁（运行中电压/温度突变）→ 内存接口时钟失效 → 固件/硬件必须降频或复位重训。
- 与内核的衔接：CPUFreq/DVFS 调频时，驱动会协调内存控制器的频率档位（避免训练失效）。
